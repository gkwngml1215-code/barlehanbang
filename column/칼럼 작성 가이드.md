칼럼은 **어드민**에서 씁니다. 로컬 `http://localhost:8080/admin/` (비밀번호) 또는 인터넷 `https://barlehanbang-admin.pages.dev` (아이디·비밀번호 + GitHub 접속 키). 저장하면 칼럼 페이지 → 목록 → 메인 칼럼 6개 → 관련 진료 페이지 → SEO·sitemap·RSS 까지 자동으로 갱신됩니다.

## 본문 쓰는 법 (GEO/AEO)

1. **도입 2~3문단** — 진료실에서 들은 환자 질문이나 장면으로 시작.
2. **H2 는 질문형** — 환자가 AI·검색창에 칠 문장 그대로. 예) "벨마비는 왜 생기나요?", "몇 개월 지난 안면마비도 회복되나요?"
3. **H2 바로 아래 정답 박스** (툴바 ▣ 정답 박스) — 첫 문장에 결론, 이어서 근거 한 문장. AI 검색이 이 문장을 그대로 인용합니다.
4. **표·체크리스트 1개 이상** — 툴바 ▦ 표 / ✓ 체크리스트. 이미지 속 글자는 검색이 못 읽습니다.
5. **숫자·기준 명시** — "3주", "HB Grade IV", "150~200개 자침", "65병상", "7~10% 재발".
6. **"바를정한방병원에서는 이렇게 치료합니다"** H2 — 관련 진료 페이지로 내부링크 (🔗 링크, 주소는 `/facial-palsy/treatment/` 처럼 `/` 로 끝나는 경로).
7. 소제목 3~5개, 본문 1,500~3,000자. H2 는 자동으로 목차가 됩니다.

## 의료광고법 체크 (저장 전 확인)

- "완치", "100%", "최고", "유일", "부작용 없음" 금지 → "개선을 기대할 수 있습니다", "~로 알려져 있습니다"
- 수치·통계에는 출처(참고 자료) 표기
- 치료 전후 사진, 환자 후기·체험담, 연예인 사진 금지
- 비급여 비용 할인·이벤트 표현 금지
- 치료 기간·횟수는 "개인차가 있지만 보통 …" 형태
